# Northstar Login Dashboard

A small responsive login and dashboard demo built with plain HTML, CSS, and JavaScript.

## Run it

Open `index.html` in a browser. No build tools or dependencies are required.

Enter any valid email address and a non-empty password to open the dashboard. The password is not saved. The demo keeps the email in browser `sessionStorage` until you sign out or close the tab.

## Interactions

- Show or hide the password field.
- Navigate between Overview, Projects, and Team.
- Search the recent activity list.
- Use the New project button to see a demo notification.
- Sign out to return to the login form.

## Limitations

This is a front-end prototype, not an authentication system. It does not verify credentials or connect to a server. Do not use it to protect real accounts or data.
